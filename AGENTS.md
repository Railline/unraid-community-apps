# Agent Notes: Unraid Community Apps Share Repo

## Purpose

Share repository for Unraid Community Applications templates/plugins and assets.

## Contents

- CrowdSec Unraid Bouncer plugin/template/assets.
- NPMplus Unraid template/assets.
- Other shareable Unraid templates may be added here instead of creating many small repos.

## Rules

- Do not include private server data, real tokens, cookies, local logs, or appdata.
- README should explain what each template/plugin is and how to install it.
- Keep icons referenced by templates available in the repo.
- Respect Community Applications expectations: clear template XML, support/project links, stable raw URLs.
